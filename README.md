# Лабораторна робота № 8

Задача комівояжера генетичним і мурашиним алгоритмами. Варіант 12, Хмельницький.

- `ЛР8_Лопатін_12.ipynb` — код, перевірки та результати виконання.
- `lr8_результат_12.json` — вимірювання, параметри, маршрути та декларація.
- `lr8_маршрут_12.html` — інтерактивна карта з чотирма шарами.
- `lr5_результати.json` і `osm_хмельницький/` — вхідні дані для відтворення ЛР8.

Для запуску відкрийте ноутбук у Jupyter або VS Code з ядром Python 3.12. Встановіть залежності в це середовище командою `python -m pip install -r requirements.txt` і виконайте всі комірки з папки репозиторію. Карта використовує Leaflet і підкладку Esri, для відображення яких потрібен інтернет.
